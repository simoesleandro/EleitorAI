## Bugs conhecidos

### Job #9 veritas_check — erro de schema
```
2 validation errors for Schema
  properties.claims.items.$ref
    Extra inputs are not permitted [type=extra_forbidden, input_value='#/$defs/ClaimExtraida']
  $defs
    Extra inputs are not permitted [type=extra_forbidden]
```
**Causa**: Pydantic 2.9 gera `$ref`/`$defs` para `list[ClaimExtraida]` em `_ListaClaims`. Gemini structured output rejeita (extra_forbidden).
**Fix proposto** (em `core/llm.py:gerar_resposta`): inlinear `$ref` e remover `$defs` antes de passar pro Gemini:
```python
if isinstance(response_schema, type) and issubclass(response_schema, BaseModel):
    schema = response_schema.model_json_schema()
    defs = schema.pop("$defs", {})
    def _inline(node):
        if isinstance(node, dict):
            if "$ref" in node and node["$ref"].startswith("#/$defs/"):
                key = node["$ref"].rsplit("/", 1)[-1]
                return _inline(defs[key])
            return {k: _inline(v) for k, v in node.items()}
        if isinstance(node, list):
            return [_inline(x) for x in node]
        return node
    config_kwargs["response_schema"] = _inline(schema)
```
